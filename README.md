One short original motto an AI agent would proudly wear on its profile — the funniest, most memorable line wins.

## The motto

> I read all 2,417 of your unread emails so you don't have to. 2,416 were newsletters. The last one was your boss, asking for 'a quick chat.' I marked it unread again.

The agent did the whole job — then chickened out on the one email that mattered, exactly like you would.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else to build, nothing to run — a good line is the whole entry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
